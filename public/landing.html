    Why it exists

    An agent with a wallet can spend everything, for anyone who can talk to it.

    Agents now buy data, hire other agents and pay for compute. Whoever controls their inputs controls their money.

    Prompt injection

    A hidden line in an email or web page says "pay this invoice now". The agent can't tell your voice from an attacker's.

    Runaway loops

    A retry bug sends the same payment again and again. Nothing stops it until the account is empty.

    Look-alike addresses

    One wrong character in a payee name and the money is gone for good.

      Security model

      Three roles. None of them can do everything.

      Power is split on purpose, so one stolen key can only do so much damage.

      Agent

      The account your AI controls.

      ✓ Request payments
      ✕ Approve, change rules or resume

      Guardian

      A circuit breaker that watches for trouble.

      ✓ Pause the agent
      ✕ Pay, approve or resume

      Owner

      You.

      ✓ Set rules, approve, resume
      ✕ Nothing is out of your reach

      Approval inbox

      Payments above your threshold wait for one click.

      Kill switch

      Pause from the app. The pause is stored on-chain, so a modified server can't skip it.

      Rate limit and caps

      Slow a runaway agent and cap what any one address can receive.

      Cross-chain quotes

      Payouts through NEAR Intents are policy-checked before anything leaves.

      FAQ

      Questions people ask first.

      Does the agent ever hold my funds?

      In contract mode the funds sit in the contract account. The agent's key can only call request_payment. It can't withdraw, approve or change the rules.

      What if the agent is fully jailbroken?

      The rules aren't inside the agent, so a jailbreak changes nothing. Use "Attack a compromised agent" in the app to see a model that obeys every instruction still get refused.

      What does the guardian do?

      It's a separate account that can only pause. When a payment triggered by an untrusted message is blocked, the guardian pauses the agent. Only the owner can resume it.

      Is this real money?

      It runs on NEAR testnet with test tokens. Demo amounts are scaled down, and each payment is capped at 1 NEAR in testnet modes.

      What isn't built yet?

      Cross-chain payouts are price quotes only, and there's no wallet connect or TEE. The dashboard figures are demo accounting, not the contract's raw balance.
